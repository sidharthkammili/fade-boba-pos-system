## Collaboration Context

This was a five-person team project. Features were integrated into a shared codebase and often depended on work from other team members.

For example, an accessibility feature could touch shared React components created by another teammate, while a reporting feature could depend on database structures or backend services contributed elsewhere. For that reason, this public copy keeps the full project context visible while clearly identifying the work that was specifically assigned to me.

## Why This Repository Is a Copy

The semester project was originally stored in a private Texas A&M course GitHub organization. To make the code viewable to recruiters, I copied the project into my personal GitHub account and sanitized it before publishing.

The public copy removes or replaces private information such as:

- Course-hosted database credentials
- API keys
- Environment files
- Personal account information
- Private deployment configuration
- Image assets whose public licensing could not be verified

As a result, the commit history in this repository begins with the public portfolio copy and does not reproduce the original semester-long team commit history.
